# EduGenie

EduGenie is a lightweight AI-powered educational assistant.

It provides:

- Question answering
- Concept explanations
- AI-generated quizzes
- Educational text summarization
- Personalized learning paths

The application uses:

- Python
- FastAPI
- Google Gemini
- HTML
- CSS
- JavaScript
- Jinja2
